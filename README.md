# 🚀 Learn SQL From Scratch - Kelas23

Welcome to the official repository for the **SQL From Scratch** video series by **Kelas23**! 

This repository contains all the code snippets, database schemas, and practice scripts featured in the video tutorials. 
Whether you are a beginner or refreshing your database skills, you can follow along, copy the scripts, and test them out yourself.

---

## 🛠️ Tools Used
- **SQL Engine:** MySQL
- **Execution Platform:** SQL One Compiler / Web-based SQL Editor

---

## 💻 How to Use

1. Open your preferred SQL environment or an online editor like [OneCompiler MySQL](https://onecompiler.com/mysql).
2. Open the `.sql` file corresponding to the video lesson you are watching.
3. Copy the script, paste it into your SQL editor, and hit **Run/Execute**.
